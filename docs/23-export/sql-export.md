# SQL Export Engine

## Structure

### Header

Comment block: generated by BLG, date, layout name, database.

### Phases

| Phase | Content |
|---|---|
| 1 | CREATE TABLE scripts |
| 2 | ALTER TABLE ADD FK |
| 3 | CREATE INDEX |
| 4 | CREATE VIEW |
| 5 | CREATE PROCEDURE |
| 6 | CREATE TRIGGER |
| 7 | INSERT seed data |
| 8 | GRANT permissions |

### Footer

Completion comment.

## Transactions

Each phase wrapped in BEGIN/COMMIT transaction.

## Rollback

Rollback section at bottom (commented out).

## Encoding

UTF-8 with BOM for SQL Server.
