# XML Export Engine

## DataSource XML

- Valid Bravo format
- UTF-8 encoding
- Proper indentation (2 spaces)

## Layout XML

- Valid Bravo format
- ZIP wrapped for Bravo import (adm-zip already available)

## File Naming

- `{FormName}_Layout1.xml`
- `{FormName}__DataSource_.xml`

## Validation

- XML parsed before export
- Errors shown to user

## BOM

- Optional, configurable
