# Export Format Catalog

## Formats

| # | Format | Extension | Encoding | MIME Type |
|---|---|---|---|---|
| 1 | SQL File | .sql | UTF-8 | text/sql |
| 2 | XML File | .xml | UTF-8 | text/xml |
| 3 | JSON File | .json | UTF-8 | application/json |
| 4 | ZIP Bundle | .zip | N/A | application/zip |
| 5 | Clipboard | N/A | UTF-8 | text/plain |
| 6 | Individual Files | varies | UTF-8 | varies |

## Details

1. **SQL File (.sql)** - Ordered scripts with comments
2. **XML File (.xml)** - Single XML (DataSource or Layout)
3. **JSON File (.json)** - Metadata export
4. **ZIP Bundle (.zip)** - All outputs in structured folders
5. **Clipboard** - Copy any single output
6. **Individual Files** - Download each output separately
