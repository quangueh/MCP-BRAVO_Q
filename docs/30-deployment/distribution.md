# Distribution Strategy

## Channels

| Channel | Method |
|---|---|
| Internal | Network share (`\server\apps\blg\`) |
| Auto-update | GitHub releases page |
| Offline | USB with installer + `latest.yml` |

## Version Control

- Tag-based releases (`v1.0.0`)

## Notification

- In-app banner when new version available

## Rollback

- Keep 3 previous versions on network share

## Tracking

- Count downloads from GitHub releases
