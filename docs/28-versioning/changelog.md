# Changelog Strategy

## Format

- Keep a Changelog (keepachangelog.com)

## Categories

- Added
- Changed
- Deprecated
- Removed
- Fixed
- Security

## Source

- Conventional commits (`feat:`, `fix:`, `chore:`, etc.)

## Tool

- standard-version or conventional-changelog

## Release Command

```
npm run release
```

- Bumps version
- Generates changelog
- Creates git tag

## Distribution

- Changelog included in installer and GitHub release notes
