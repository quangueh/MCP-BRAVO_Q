# API Documentation Format

## Public APIs

TypeScript interfaces and functions with JSDoc.

## Format

- Function signature
- Parameters table
- Return type
- Example code
- Error cases

## Engine APIs

- Each engine exposes public methods only

## IPC APIs

- Channel name
- Request/response types
- Error codes

## Auto-generation

- TypeDoc from JSDoc comments

## Output

- HTML docs in `docs/api/`
