# Diagnostic Tools

## Tools

| # | Tool | Description |
|---|---|---|
| 1 | Connection test | Ping DB, measure latency |
| 2 | Schema validation | Compare cached vs live schema |
| 3 | XML validation | Parse all cached layouts, report errors |
| 4 | Cache health | Check sizes, hit rates, corruption |
| 5 | Log export | Bundle logs for support |
| 6 | Reset | Clear cache, reset settings, fresh start |

## UI

- Settings -> Diagnostics -> Run All

## Output

- Report with pass/fail per check
- Exportable as text
