# Installation Flow

## Steps

1. User runs setup.exe
2. Welcome screen
3. License agreement
4. Install location (default: `%LOCALAPPDATA%/BLG`)
5. Start menu shortcut
6. Desktop shortcut (optional)
7. Install progress
8. Launch app (optional)

## Prerequisites

- .NET 4.8 (checked automatically)
- Node.js bundled in Electron (no separate install)

## Uninstall

- Windows Programs and Features
- Clean removal (no leftover files)
