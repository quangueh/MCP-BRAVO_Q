# Schema Inventory

## Overview

Bravo ERP uses two SQL Server databases on the same server instance.

| Database | Purpose | Stored Procedures | Views | Tables |
|---|---|---|---|---|
| **Bravo_Config** | Configuration, master data, stored procedures, views | 2,253 | 1,593 | ~120 |
| **Bravo_Data** | Transaction data, document lines, postings | 0 | 0 | ~98 |
| **Total** | | **2,253** | **1,593** | **~218** |

---

## Database: Bravo_Config

Houses all configuration tables, master data, stored procedures, and views.

### Purpose

- System configuration and parameters
- Master data definitions (customers, vendors, items, accounts)
- All stored procedure definitions
- All view definitions
- User and security configuration
- Report templates and layouts

---

## Database: Bravo_Data

Houses all transactional data generated by business operations.

### Purpose

- Financial transaction documents
- Document lines and details
- Accounting postings and journals
- Inventory movements
- Budget actuals
- Approval workflow history

---

## Table Naming Convention

All table names follow the pattern `B{Prefix}{Name}` in PascalCase.

| Prefix | Domain | Examples | Count |
|---|---|---|---|
| **B00** | System configuration | B00SysConfig, B00Users, B00Branch | ~15 |
| **B10** | Accounting / Financial | B10AccYear, B10AccPeriod, B10ChartOfAcc | ~35 |
| **B20** | Master data | B20Customer, B20Vendor, B20Product | ~60 |
| **B30** | Transaction data | B30BizDoc, B30BillDoc, B30AccDoc | ~108 |

---
