# Command Generation Rules

## Overview

CommandCollection defines the SQL commands for INSERT, UPDATE, and DELETE operations. BLG auto-generates these commands from table metadata following strict rules.

---

## INSERT Command

### Rules

1. Include all editable columns (exclude Identity, computed)
2. Exclude audit columns that are auto-set (CreatedDate, ModifiedDate)
3. Map each column to a parameter
4. Use parameterized SQL for security

### Column Filtering

| Column Type | Include in INSERT? | Notes |
|---|---|---|
| Id (Identity) | No | Auto-generated by database |
| Regular columns | Yes | All business columns |
| IsActive | Yes | Default to 1 |
| CreatedBy | Yes | From current user context |
| CreatedDate | Yes | Use GETDATE() |
| ModifiedBy | No | Set on update only |
| ModifiedDate | No | Set on update only |
| Computed columns | No | Calculated by database |

### XML Template

```xml
<Command Name="Insert{TableName}" Type="INSERT">
    <Text>
        INSERT INTO {TableName}
        ({Column1}, {Column2}, {Column3}, ..., IsActive, CreatedBy, CreatedDate)
        VALUES
        (@{Column1}, @{Column2}, @{Column3}, ..., 1, @nUserId, GETDATE())
    </Text>
    <Parameters>
        <Parameter Name="{Column1}" DbType="{Type1}" SourceColumn="{Column1}" />
        <Parameter Name="{Column2}" DbType="{Type2}" SourceColumn="{Column2}" />
        <Parameter Name="{Column3}" DbType="{Type3}" SourceColumn="{Column3}" />
    </Parameters>
</Command>
```

### Example: B20Customer INSERT

```xml
<Command Name="InsertCustomer" Type="INSERT">
    <Text>
        INSERT INTO B20Customer
        (Code, Name, TaxCode, Address, Phone, Email, IsActive, CreatedBy, CreatedDate)
        VALUES
        (@Code, @Name, @TaxCode, @Address, @Phone, @Email, 1, @nUserId, GETDATE())
    </Text>
    <Parameters>
        <Parameter Name="Code" DbType="VARCHAR(50)" SourceColumn="Code" />
        <Parameter Name="Name" DbType="NVARCHAR(255)" SourceColumn="Name" />
        <Parameter Name="TaxCode" DbType="VARCHAR(20)" SourceColumn="TaxCode" />
        <Parameter Name="Address" DbType="NVARCHAR(500)" SourceColumn="Address" />
        <Parameter Name="Phone" DbType="VARCHAR(20)" SourceColumn="Phone" />
        <Parameter Name="Email" DbType="VARCHAR(100)" SourceColumn="Email" />
    </Parameters>
</Command>
```

## UPDATE Command

### Rules

1. Include all editable columns as SET clause parameters
2. Include Id as WHERE clause parameter
3. Always update ModifiedBy and ModifiedDate
4. Use parameterized SQL

### Column Filtering

| Column Type | Include in UPDATE? | Notes |
|---|---|---|
| Id (PK) | Yes (WHERE only) | Used in WHERE clause |
| Regular columns | Yes | All business columns |
| IsActive | Yes | Can be toggled |
| CreatedBy | No | Never changes |
| CreatedDate | No | Never changes |
| ModifiedBy | Yes | Set to current user |
| ModifiedDate | Yes | Use GETDATE() |
| Computed columns | No | Calculated by database |

### XML Template

```xml
<Command Name="Update{TableName}" Type="UPDATE">
    <Text>
        UPDATE {TableName}
        SET {Column1} = @{Column1},
            {Column2} = @{Column2},
            {Column3} = @{Column3},
            ModifiedBy = @nUserId,
            ModifiedDate = GETDATE()
        WHERE Id = @Id
    </Text>
    <Parameters>
        <Parameter Name="Id" DbType="INT" SourceColumn="Id" />
        <Parameter Name="{Column1}" DbType="{Type1}" SourceColumn="{Column1}" />
        <Parameter Name="{Column2}" DbType="{Type2}" SourceColumn="{Column2}" />
    </Parameters>
</Command>
```

### Example: B20Customer UPDATE

```xml
<Command Name="UpdateCustomer" Type="UPDATE">
    <Text>
        UPDATE B20Customer
        SET Code = @Code,
            Name = @Name,
            TaxCode = @TaxCode,
            Address = @Address,
            Phone = @Phone,
            Email = @Email,
            ModifiedBy = @nUserId,
            ModifiedDate = GETDATE()
        WHERE Id = @Id
    </Text>
    <Parameters>
        <Parameter Name="Id" DbType="INT" SourceColumn="Id" />
        <Parameter Name="Code" DbType="VARCHAR(50)" SourceColumn="Code" />
        <Parameter Name="Name" DbType="NVARCHAR(255)" SourceColumn="Name" />
        <Parameter Name="TaxCode" DbType="VARCHAR(20)" SourceColumn="TaxCode" />
        <Parameter Name="Address" DbType="NVARCHAR(500)" SourceColumn="Address" />
        <Parameter Name="Phone" DbType="VARCHAR(20)" SourceColumn="Phone" />
        <Parameter Name="Email" DbType="VARCHAR(100)" SourceColumn="Email" />
    </Parameters>
</Command>
```

## DELETE Command (Soft Delete)

### Rules

1. NEVER perform hard deletes
2. Set IsActive = 0 (soft delete)
3. Update ModifiedBy and ModifiedDate
4. Only requires Id parameter
5. Check for referencing records before delete

### XML Template

```xml
<Command Name="Delete{TableName}" Type="DELETE">
    <Text>
        UPDATE {TableName}
        SET IsActive = 0,
            ModifiedBy = @nUserId,
            ModifiedDate = GETDATE()
        WHERE Id = @Id
    </Text>
    <Parameters>
        <Parameter Name="Id" DbType="INT" SourceColumn="Id" />
    </Parameters>
</Command>
```

### Example: B20Customer DELETE

```xml
<Command Name="DeleteCustomer" Type="DELETE">
    <Text>
        UPDATE B20Customer
        SET IsActive = 0,
            ModifiedBy = @nUserId,
            ModifiedDate = GETDATE()
        WHERE Id = @Id
    </Text>
    <Parameters>
        <Parameter Name="Id" DbType="INT" SourceColumn="Id" />
    </Parameters>
</Command>
```

## Complete CommandCollection Template

```xml
<CommandCollection>
    <!-- INSERT -->
    <Command Name="Insert{Table}" Type="INSERT">
        <Text>
            INSERT INTO {Table} ({Cols}, IsActive, CreatedBy, CreatedDate)
            VALUES ({@Params}, 1, @nUserId, GETDATE())
        </Text>
        <Parameters>{InsertParams}</Parameters>
    </Command>

    <!-- UPDATE -->
    <Command Name="Update{Table}" Type="UPDATE">
        <Text>
            UPDATE {Table}
            SET {Col} = @{Col}, ..., ModifiedBy = @nUserId, ModifiedDate = GETDATE()
            WHERE Id = @Id
        </Text>
        <Parameters>{UpdateParams}</Parameters>
    </Command>

    <!-- DELETE (Soft) -->
    <Command Name="Delete{Table}" Type="DELETE">
        <Text>
            UPDATE {Table}
            SET IsActive = 0, ModifiedBy = @nUserId, ModifiedDate = GETDATE()
            WHERE Id = @Id
        </Text>
        <Parameters>
            <Parameter Name="Id" DbType="INT" SourceColumn="Id" />
        </Parameters>
    </Command>
</CommandCollection>
```

---

## Command Generation Algorithm

```
FOR each table:
    1. INSERT Command:
       - Cols = all columns EXCEPT Id (Identity), ModifiedBy, ModifiedDate
       - Params = one @param per column
       - Append IsActive=1, CreatedBy=@nUserId, CreatedDate=GETDATE()

    2. UPDATE Command:
       - SET = all columns EXCEPT Id, CreatedBy, CreatedDate
       - Append ModifiedBy=@nUserId, ModifiedDate=GETDATE()
       - WHERE Id = @Id

    3. DELETE Command:
       - SET IsActive=0, ModifiedBy=@nUserId, ModifiedDate=GETDATE()
       - WHERE Id = @Id
```
