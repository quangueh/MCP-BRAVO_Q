# Bravo Expression Language

| Expression | Returns |
|-----------|---------|
| {=BRANCH()} | Current branch code |
| {=USER(Id)} | Current user ID |
| {=USER(IsSysAdmin)} | 1 if admin |
| {=LANGID()} | Language ID (0=VN) |
| {=GETDATE()} | Current datetime |
| {=ISNULL(field, default)} | field or default |
| IIF(cond, true, false) | Conditional value |
