# Config File Structure

## Root Config Files

```
blg/
|-- .env                        # Environment variables (git-ignored)
|-- .env.example                # Example env file (version controlled)
|
|-- config/
|   |-- default.json            # Default application settings
|   |-- schemas/
|       |-- table-schema.json   # JSON Schema for table validation
|       +-- layout-schema.json  # JSON Schema for layout validation
|
|-- templates/
|   |-- sql/
|   |   |-- create-table.ejs    # CREATE TABLE template
|   |   |-- foreign-key.ejs     # ALTER TABLE FK template
|   |   |-- index.ejs           # CREATE INDEX template
|   |   |-- crud-sp.ejs         # CRUD stored procedure template
|   |   |-- report-sp.ejs       # Report stored procedure template
|   |   |-- view.ejs            # CREATE VIEW template
|   |   |-- trigger.ejs         # Audit trigger template
|   |   +-- seed-data.ejs       # INSERT seed data template
|   |
|   |-- xml/
|   |   |-- explorer-toolbar.ejs    # Explorer toolbar buttons
|   |   |-- editor-toolbar.ejs      # Editor toolbar buttons
|   |   |-- report-toolbar.ejs      # Report toolbar buttons
|   |   |-- header-style.ejs        # Header style definition
|   |   |-- grid-style.ejs          # Grid style definition
|   |   +-- button-style.ejs        # Button style definition
|   |
|   +-- sp/
|       |-- select-sp.ejs       # SELECT stored procedure template
|       +-- insert-sp.ejs       # INSERT stored procedure template
|
+-- knowledge/
    |-- schemas/
    |   |-- tables.json         # Extracted table metadata
    |   |-- columns.json        # Extracted column metadata
    |   +-- foreign-keys.json   # Extracted FK metadata
    |
    +-- layouts/
        |-- explorers.json      # Parsed Explorer layouts
        |-- editors.json        # Parsed Editor layouts
        +-- reports.json        # Parsed Report layouts
```

---

## File Purposes

### `.env` / `.env.example`

```
# Database connection
DB_SERVER=localhost
DB_PORT=1433
DB_USER=sa
DB_PASSWORD=your_password_here
DB_DATABASE=BravoDB

# App settings
LOG_LEVEL=info
CACHE_DIR=.cache
OUTPUT_DIR=output
```

### `templates/sql/create-table.ejs`

```sql
-- Generated by Bravo Layout Generator
-- Table: <%= tableName %>
-- Date: <%= generatedDate %>

CREATE TABLE <%= schema %>.<%= tableName %> (
<% columns.forEach(function(col, i) { %>
    <%= col.name %> <%= col.sqlType %><% if (col.nullable) { %> NULL<% } else { %> NOT NULL<% } %><% if (col.defaultValue) { %> DEFAULT <%= col.defaultValue %><% } %><% if (i < columns.length - 1) { %>,<% } %>
<% }); %>
    CONSTRAINT PK_<%= tableName %> PRIMARY KEY (<%= primaryKey %>)
);
```

### `knowledge/` Directory

Pre-extracted metadata for offline/fast access:
- `tables.json` - All table names and basic info
- `columns.json` - All columns with types and properties
- `foreign-keys.json` - All FK relationships
- Layout JSON files - Parsed layout metadata
